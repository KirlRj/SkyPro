# Проект "Обучение SkyPro"

## Описание:

Проект "Обучение SkyPro" это выполнение домашнего задания по курсу "Python разработчик"

На текущий момент в проекте есть следующая функциональность:
1. get_mask_card_number - функция возвращает маску номера карты по правилу XXXX XX** **** XXXX.
2. get_mask_account - функция возвращает маску номера счета по правилу **XXXX.
3. mask_account_card - функция возвращает маску. Для карты XXXX XX** **** XXXX. Для счета **XXXX.
4. get_date - функция преобразует дату в формат 'DD.MM.YYYY.
5. filter_by_state - функция возвращает новый список словарей, содержащие ключ state == входному значению.
6. sort_by_date - функция сортирует список словарей по дате. По умолчанию - убывание.
7. filter_by_currency - функция, возвращающая по очереди транзакции, по ключу currency.
8. transaction_descriptions - функция, возвращающая описание операции.
9. card_number_generator - генератор карт по порядку.
10. log - декоратор логирования функций. С помощью него можно узнать время запуска функции, время окончания функции, время работы функции, входящие и исходящие данные, статус выполнения. Так же добавлен функционал записи логов в файл (при необходимости).
11. read_json - чтение json файла и вывод в список словарей. Если есть ошибки в файле, то выводится пустое значение.
12. transfer_currency - вывод суммы транзакции в рублях. Если валюта не в рублях, то идет обращение к внешнему API для конвертации валюты в рубли и определении суммы в рублях.

## Тестирование:

Для тестирования использовался фреймворк pytest.
Если у вас его нет, то скопируйте команду для установки.
```
poetry add --group dev pytest
```
Для проверки покрытия тестами, использовалась библиотека pytest-cov.
Если ее нет, то скопируйте команду для установки.
```
poetry add --group dev pytest-cov
```
Для проверки покрытия тестами используйте команду.
```
poetry run pytest --cov
```
Для формирования отчета об покрытии тестами в формате HTML, используйте команду.
```
pytest --cov=src --cov-report=html
```
где src - пакет с модулями, которые тестируются.
Отчет будет находиться в htmlcov/index.html
